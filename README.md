# IranRobot Invoice — پیش‌فاکتور ساز ایران ربات

برنامهٔ آفلاین اندروید مبتنی بر Flutter برای صدور پیش‌فاکتور فارسی مطابق نمونه ایران ربات.

## قابلیت‌ها
- ساخت، ویرایش، حذف و تکثیر پیش‌فاکتور و نگهداری روی دستگاه
- مشخصات فروشنده و خریدار، شماره و تاریخ شمسی
- اقلام، تعداد، واحد، قیمت، تخفیف، مالیات، جمع کل و چهار واحد پول
- PDF افقی A4 قابل چاپ و اشتراک با امضا و لوگوی انتخابی

## ساخت APK
در GitHub Actions گردش‌کار «Android APK» را اجرا کنید. فایل `app-release.apk` پس از موفقیت در Artifacts قرار می‌گیرد.

## اجرای محلی
```bash
python3 scripts/fetch_fonts.py
flutter create --platforms=android --project-name=iranrobot_invoice --org=ir.iranrobot .
flutter pub get
flutter run
```
فونت Vazirmatn در زمان ساخت از منبع متن‌باز دانلود و در APK قرار می‌گیرد. اپ پس از نصب آفلاین است. داده‌ها در خود دستگاه ذخیره می‌شوند؛ حذف برنامه ممکن است آن‌ها را پاک کند.

این خروجی پیش‌فاکتور تجاری است، نه صورتحساب قانونی سامانه مودیان.
